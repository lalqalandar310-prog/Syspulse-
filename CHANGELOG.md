# Changelog

All notable changes to SysPulse are documented here.

## [1.0.0] - 2026-09-15

### Added
- Real-time process monitoring with full file paths
- USB device connection alerts
- Windows startup change detection
- CPU/RAM/Disk threshold monitoring
- Telegram notifications
- Daily summary reports
- HWID-based licensing
- Configuration file (config.ini)

### Security
- No cloud storage
- Local-only operation
- HTTPS for Telegram
- Whitelist support

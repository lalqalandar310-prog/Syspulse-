# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SysPulse,
please report it privately.

**Please do NOT open a public GitHub issue.**

Contact: **darkssel@proton.me**

We aim to respond within 48 hours.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Active |

## Security Features

- HWID-based licensing (no personal data)
- Local-only operation
- No cloud storage
- HTTPS for all communications
- No telemetry

## What SysPulse Does NOT Do

- ❌ Does not upload your files
- ❌ Does not scan personal files
- ❌ Does not collect usage analytics
- ❌ Does not require a cloud account
